# country code for location

Get country code

## Usage

``` r
GNcountryCode(lat, lng, lang = "", radius = "")
```

## Arguments

- lat:

  latitude

- lng:

  longitude

- lang:

  language code

- radius:

  radius size

## Value

country record

## Details

country code for location

API doc for GNcountryCode is at
<http://www.geonames.org/export/web-services.html#countrycode>
