# weather at location

get weather at location

## Usage

``` r
GNfindNearByWeather(lat, lng)
```

## Arguments

- lat:

  latitude

- lng:

  longitude

## Value

weather record

## Details

get weather

API doc for GNfindNearByWeather is at
<http://www.geonames.org/export/JSON-webservices.html#findNearByWeatherJSON>

## Note

check capitalisation of 'NearBy'
