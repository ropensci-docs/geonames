# weather stations in box

weather stations in region

## Usage

``` r
GNweather(north, east, south, west, maxRows = 10)
```

## Arguments

- north:

  north bound

- east:

  east bound

- south:

  south bound

- west:

  west bound

- maxRows:

  max records to return

## Value

weather records

## Details

get weather stations in region with latest readings
