# nearby wikipedia entries

find nearby wikipedia entries

## Usage

``` r
GNfindNearbyWikipedia(...)
```

## Arguments

- ...:

  see geonames.org documentation

## Value

wikipedia entries

## Details

search wikipedia entries by lat/lng or location name parameters

API doc for GNfindNearbyWikipedia is at
<http://www.geonames.org/export/wikipedia-webservice.html#findNearbyWikipedia>

## Author

Barry Rowlingson

## Examples

``` r
if (FALSE) { # \dontrun{
GNfindNearbyWikipedia(postalcode=8775,country="CH",radius=10)
} # }
```
