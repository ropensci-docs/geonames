# nearest intersection

search US for nearest intersection

## Usage

``` r
GNfindNearestIntersection(lat, lng)
```

## Arguments

- lat:

  latitude

- lng:

  longitude

## Value

intersection record

## Details

finds nearest intersection

API doc for GNfindNearestIntersection is at
<http://www.geonames.org/maps/us-reverse-geocoder.html#findNearestIntersection>
