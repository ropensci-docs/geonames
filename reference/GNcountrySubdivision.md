# country code and subdivision

country code and admin subdivision

## Usage

``` r
GNcountrySubdivision(lat, lng, lang = "en", radius = "",
  maxRows = 10)
```

## Arguments

- lat:

  latitude

- lng:

  longitude

- lang:

  language code

- radius:

  search radius

- maxRows:

  max number of returned records

## Value

iso country code

## Details

looks up country and admin subdivisions

API doc for GNcountrySubdivision is at
<http://www.geonames.org/export/web-services.html#countrysubdiv>
