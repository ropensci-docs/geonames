# nearby street finding

find nearby streets (US only)

## Usage

``` r
GNfindNearbyStreets(lat, lng)
```

## Arguments

- lat:

  latitude

- lng:

  longitude

## Value

street records

## Details

for a lat-long, find nearby US streets

API doc for GNfindNearbyStreets is at
<http://www.geonames.org/maps/us-reverse-geocoder.html#findNearbyStreets>
