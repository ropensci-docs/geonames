# search wikipedia

wikipedia fulltext search

## Usage

``` r
GNwikipediaSearch(q, maxRows = 10)
```

## Arguments

- q:

  search string

- maxRows:

  maximum returned records

## Value

wikipedia entries

## Details

find geolocated articles in wikipedia

API doc for GNwikipediaSearch is at
<http://www.geonames.org/export/wikipedia-webservice.html#wikipediaSearch>
