# srtm3 height

height from srtm3 data

## Usage

``` r
GNsrtm3(lat, lng)
```

## Arguments

- lat:

  latitude

- lng:

  longitude

## Value

height record

## Details

get srtm3 height

API doc for GNsrtm3 is at
<http://www.geonames.org/export/web-services.html#srtm3>
