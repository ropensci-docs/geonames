# ICAO weather station data

weather record from ICAO station

## Usage

``` r
GNweatherIcao(ICAO)
```

## Arguments

- ICAO:

  ICAO code

## Value

weather record

## Details

get most recent ICAO station data

API doc for GNweatherIcao is at
<http://www.geonames.org/export/JSON-webservices.html#weatherIcaoJSON>
