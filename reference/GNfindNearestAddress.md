# nearest address

find nearest street and address

## Usage

``` r
GNfindNearestAddress(lat, lng)
```

## Arguments

- lat:

  latitude

- lng:

  longitude

## Value

address record

## Details

search US for nearest street and address

API doc for GNfindNearestAddress is at
<http://www.geonames.org/maps/us-reverse-geocoder.html#findNearestAddress>
