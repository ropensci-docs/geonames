# wikipedia articles in a box

wikipedia articles in bounding box

## Usage

``` r
GNwikipediaBoundingBox(...)
```

## Arguments

- ...:

  parameters (north, south, east, west etc.)

## Value

wikipedia records

## Details

find articles in a box

API doc for GNwikipediaBoundingBox is at
<http://www.geonames.org/export/wikipedia-webservice.html#wikipediaBoundingBox>

## Author

Barry Rowlingson

## Examples

``` r
if (FALSE) { # \dontrun{
GNwikipediaBoundingBox(north=44.1,south=-9.9,east=-22.4,west=55.2)
} # }
```
