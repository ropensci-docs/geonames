# topo30 height

height from topo30

## Usage

``` r
GNgtopo30(lat, lng)
```

## Arguments

- lat:

  latitude

- lng:

  longitude

## Value

height record

## Details

get height from topo30 data

API doc for GNgtopo30 is at
<http://www.geonames.org/export/web-services.html#gtopo30>
